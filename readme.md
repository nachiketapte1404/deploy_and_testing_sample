This is a sample task manager website created for Deployment and Testing using Angular and SpringBoot<br/>
Note - Dummy tasks have been added as this project is for security and tests execution.<br/>
The functionality to add/edit/delete tasks has not been implemented yet.<br>
<br/>
Please run npm i inside task-manager-ui folder after cloning the project.
<br>
Versions:
Angular - 17 <br>
Java - 21

To run the project, do - docker compose up --build
